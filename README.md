# Maryam Al Balushi

A one-page portfolio. On a phone it fills the screen like a phone. On a laptop it sits on the desk as an iPad. Slide up on the lock screen, then open Notes, Work, Skills, Safari, or LinkedIn.

It is a static site. GitHub Pages serves it from the `main` branch of `marymec.github.io` at [marymec.github.io](https://marymec.github.io).

## Run it locally

```bash
python3 -m http.server 4177
```

Open `http://127.0.0.1:4177`.
