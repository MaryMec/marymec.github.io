# Maryam Al Balushi

A one-page portfolio that opens like a phone. Slide up on the lock screen, then open Notes, Work, Skills, or Safari.

It is a static site. GitHub Pages serves it from the main branch of marymec.github.io.

## Run it locally

```bash
python3 -m http.server 4177
```

Open http://127.0.0.1:4177.
