# Last train

A one-page portfolio for Maryam Al Balushi. You are on the last train. A black cat sits across from you, the moon stays in the window, and four choices open the ride: Who, Made, Knows, Find.

It is a static site, so GitHub Pages can host it for free. These files belong on the main branch of marymec.github.io.

## Run it locally

```bash
python3 -m http.server 4177
```

Open http://127.0.0.1:4177.

The chapters switch without JavaScript. With JavaScript, the cat's line types itself. That motion stops when the browser asks for reduced motion.
